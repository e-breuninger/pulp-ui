# Changelog

Every entry below is generated from the commit history by
[commitizen](https://commitizen-tools.github.io/commitizen/), which also decides
the version number: a `feat` bumps the minor, a `fix` the patch, and a `!` or a
`BREAKING CHANGE:` footer the major. See [CONTRIBUTING.md](CONTRIBUTING.md) for
the commit format.
